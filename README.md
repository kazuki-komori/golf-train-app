# グリップ・スイングトレーナー

スマホをクラブのグリップに見立てて素振りし、ジャイロセンサーでスイングを判定する Web アプリです。
基準を満たすまで「合格」にならず、決めた回数だけ連続で合格するまで終われません。
Android の Chrome で使う想定です。

## 1回振るとわかること

- **合否と理由**: フェースの向き・テンポ・軌道・クラブの通り道。不合格だと画面が赤くなり、ブザーと振動と音声で理由を伝えます
- **ボールの行方**: このスイングで打ったらボールがどう飛ぶかを、3D の弾道（トレーサー）、キャリー、止まった所、左右のずれ、球筋の名前で表示します
- **インパクトの瞬間（真上から）**: クラブの通り道とフェースの向きを矢印で描き、球筋の早見表（3×3）で自分の位置を示します
- **スイングの軌道（3D）**: お手本の面と軌道に、実際のヘッドの通り道を重ねて表示します。下ろす線は、お手本に近いほど緑、離れるほど黄・赤になります。後ろ・正面・真上から見られ、スロー再生もできます
- **直し方のコツ**: 「いま何が起きているか」「コツ」「練習」を初心者向けの言葉で表示します

## 持ち方

1. スマホの上端を地面側（ヘッド側）に向けて、長い辺をシャフトに見立てて握る
2. 画面を目標方向に向けてアドレスする
3. 1秒静止すると「ピッ」と鳴るので、そこから素振りする

## 公開（GitHub Pages）

`main` ブランチのルートをそのまま GitHub Pages で配信しています。ビルドは不要です。
スマホのモーションセンサーは https のページでしか使えませんが、GitHub Pages は https なのでそのまま使えます。

手元で試すときは `python3 -m http.server 8000` で起動し、PC のブラウザで開くとデモボタンで疑似スイングを流せます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `engine.js` | センサー値からスイングを検出・解析（テンポ、フェース、軌道、3D のヘッド位置） |
| `flight.js` | ボールの弾道シミュレーション（空気抵抗・揚力・スピン） |
| `coach.js` | 初心者向けの説明とコツ |
| `view3d.js` | three.js による 3D 表示（スイングの軌道、ボールの行方） |
| `app.js` | 画面・音・センサーのつなぎ込み |

## 計算のしかた

- **3D の軌道**: 胸の中心を支点に、腕とクラブの2本でヘッドの位置を推定しています。スマホの向き（ジャイロの積分）だけから求めるため、体の移動（体重移動や伸び上がり）は反映されません
- **お手本**: アドレス時のシャフトと目標ラインを含む面（シャフトプレーン）の上を回る軌道です
- **ボールの飛び方**: TrackMan の考え方（打ち出しは主にフェースの向き、曲がりはフェースと通り道の差）で打ち出し条件を決め、空気抵抗と揚力を含む運動方程式を解いています。アマチュア平均（ヘッドスピード 41.8 m/s）のドライバーでキャリー約 187 m になるよう係数を合わせています

## テスト

```
node test/engine.test.mjs
```

## 制約

- センサーの取得間隔は約60Hzです。速いダウンスイングでは数サンプルしか取れないため、角度には数度の誤差があります
- 多くのスマホのジャイロは約2000°/秒で頭打ちになります
- ヘッドスピードと飛距離は手元の角速度から出した目安です。実際にボールを打った結果ではありません
- 素振り中にスマホが手から抜けないよう、ストラップを付けるなど十分に注意してください
